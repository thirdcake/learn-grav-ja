トラブルが起こったときに読むチャプターです。

## 404 Not Found{#page-not-found}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/page-not-found) （[md](https://learn.getgrav.org/troubleshooting/page-not-found.md)）

あるはずのページが見つからない場合のトラブルシューティングです。

## Grav Server Error{#server-error}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/server-error) （[md](https://learn.getgrav.org/troubleshooting/server-error.md)）

web サーバーでのエラーのうち、 Grav が出しているエラー画面になった場合のトラブルシューティングです。  
もし、 Grav まで到達していない（web サーバーソフトウェア側の問題）は、下のページを読んでください。

## 500 Internal Server Error{#internal-server-error}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/internal-server-error) （[md](https://learn.getgrav.org/troubleshooting/internal-server-error.md)）

web サーバーのエラーのうち、apache などの web サーバーソフトウェアが出しているエラー画面になった場合のトラブルシューティングです。  
もし、 Grav まで到達していて、 Grav が出しているエラー画面だった場合は、上のページを読んでください。

## 403 Forbidden{#forbidden}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/forbidden) （[md](https://learn.getgrav.org/troubleshooting/forbidden.md)）

表示が禁止されているというエラーの場合のトラブルシューティングです。

## Invalid Security Token{#invalid-security-token}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/invalid-security-token) （[md](https://learn.getgrav.org/troubleshooting/invalid-security-token.md)）

管理パネルにログインした状態で、 `Invalid Security Token` セキュリティトークンが妥当でないというエラーが出る場合のトラブルシューティングです。

## Permissions{#permissions}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/permissions) （[md](https://learn.getgrav.org/troubleshooting/permissions.md)）

Linux ユーザーのパーミッションでエラーが出る場合のトラブルシューティングです。

## Proxy の問題{#proxy}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/proxy) （[md](https://learn.getgrav.org/troubleshooting/proxy.md)）

プロキシサーバーを挟んだ環境で、 GPM コマンドにエラーが出る場合のトラブルシューティングです。

## 一般的な問題{#common-problems}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/common-problems) （[md](https://learn.getgrav.org/troubleshooting/common-problems.md)）

上記に当てはまらない、一般的な問題がある場合に読む記事です。

## htaccess{#htaccess}

[公式ドキュメント](https://learn.getgrav.org/troubleshooting/htaccess) （[md](https://learn.getgrav.org/troubleshooting/htaccess.md)）

apache2 やその互換の web サーバーで `.htaccess` を使ってルーティングを制御している場合（多くのレンタルサーバーはそのようになっています）で、うまく制御できない場合のトラブルシューティングです。
