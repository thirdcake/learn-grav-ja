管理パネルプラグイン（Admin2）の使い方について解説されているチャプターです。

Grav 1.x 系の頃と違い、管理パネルでできることは、大幅に増えました。  
そのため、Grav を GUI で使用する際には、このページが参考になります。

このページに至るまでの、前段の注意点を、少しだけ書いておきます。

## 初期設定の注意点1

CLI （黒い画面）を使いたくない場合（もしくは SSH が契約上使えない場合）、 Grav のセットアップをどうするかという問題があります。  
一般的な VPS やクラウドサービス（AWS EC2 など）を使う場合は、各種設定のため CLI 必須なので、それを扱える IT エンジニアがいらっしゃると思いますから、問題ありません。  
レンタルサーバーのとき、特にそのレンタルサーバーに「Grav の簡単インストール機能」などが無い場合が問題になります。

正攻法でやるなら以下の手順になりますが、これはうまくいきません：

1. [公式サイト](https://getgrav.org/downloads) から Grav Core + Admin2 の方をダウンロード
1. ローカル環境で zip ファイルを展開（解凍）
1. FTP などでレンタルサーバーにアップロード
1. サイトにアクセスして、管理者作成

問題は、3番目の FTP アップロードです。

Grav は、vendor ディレクトリに大量のファイルを抱え込んでいるため、おそらく、いつまで待ってもアップロードが完了しません。  
これを回避するため、 zip のままアップロードすれば、1ファイルなのですぐにアップロードが完了しますが、日本のレンタルサーバー会社（さくらやロリポップなど）は、 SSH 接続以外から zip ファイルの展開を認めていないことがあります。

私は試したことが無いのですが、 [Xserver はブラウザから zip 展開できる](https://www.xserver.ne.jp/manual/man_tool_file.php) そうです。  
このようなサービスを利用している場合は、以下の手順でできます：

1. Grav 公式から Grav core + Admin2 をダウンロード
1. FTP などでレンタルサーバーにアップロード
1. レンタルサーバーのファイルマネージャーで zip ファイルを展開
1. サイトにアクセスして、管理者作成

一方、zip 展開を SSH 以外から認めていないレンタルサーバーの場合、ネットで検索すると、裏技として、 php の ZipArchive を使う方法が見つかります。  
しかし、これはあくまで裏技であり、不具合があっても自己責任です。

このような状況があるため、 レンタルサーバーの無料期間の間に、 Grav が使えるか、セットアップできるかを試してみてください。  
アップロード後は、公式ドキュメントの通り、アップデートやログ確認などを管理パネルから行えるので、 GUI だけで管理できます。

## 初期設定の注意点2

上記の通り、 Admin2 付きの zip ファイルをアップロードして、展開した場合、サイトは「管理者の登録画面」になります。

この管理者登録は、セットアップ後すみやかに完了させてください。

WordPress などの場合は、データベース設定（パスワードなど）を知らなければ、管理者は作れない仕組みになっています。  
一方、 Grav の場合は、データベースを使いませんから、誰でも早いもの勝ちで管理者になれてしまう仕様です。

そのため、管理者を登録しないまま放置すると、誰かにサイトを乗っ取られるリスクがあります。 

この状況を回避することは可能です。たとえば：

- ローカル環境でアカウントを作ってからアップロードする
- SSH でアカウントを作ってから Admin2 を有効化する

通常の作業フローで、すぐに自分でアクセスして登録すれば過剰に恐れる必要はありませんが、「放置はNG」「仕様上のリスクがある」ということは頭に入れて作業しましょう。
