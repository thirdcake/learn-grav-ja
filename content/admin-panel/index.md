[公式ドキュメント](https://learn.getgrav.org/admin-panel) （[md](https://learn.getgrav.org/admin-panel.md)）

管理パネルプラグイン（Admin2）の使い方について解説されているチャプターです。

Grav 1.x 系の頃と比べ、 2.x 系で管理パネルが刷新され、できることも増えました。  
そのため、Grav を GUI で管理する際には、このページが参考になります。

このページに至るまでの、前段の注意点を、少しだけ書いておきます。

## 初期設定の注意点1

Grav を GUI （ブラウザ）でインストールするとき、場合によっては問題が起きる可能性があります。  
どこに Grav をインストールしたいかによります：

1. 一般的な VPS やクラウドサービス（AWS EC2 など）を使う場合は、CLI を扱える IT エンジニア（詳しい人）がいると思うので、問題ありません
1. レンタルサーバーで、 cPanel のような Grav のインストール機能が搭載されている管理パネルを使っている場合、簡単インストールができるので問題ありません
1. レンタルサーバーで、 SSH 接続でき、CLI 操作（unzip コマンドなど）ができる場合、問題ありません
1. レンタルサーバーで、ファイルシステムに zip 展開機能が搭載されている場合（XServer など）も、問題ありません

問題になるのは、上記以外の場合です。  
具体的には、ロリポップやさくらの最安プランのように、SSH 接続も zip 展開もできず、しかも Grav の簡単インストールがない場合です。

正攻法でやるなら以下の手順になりますが、これはうまくいきません：

1. [公式サイト](https://getgrav.org/downloads) から Grav Core + Admin2 の方をダウンロード
1. ローカル環境で zip ファイルを展開（解凍）
1. FTP などでレンタルサーバーにアップロード
1. サイトにアクセスして、管理者の登録

問題は、3番目の FTP アップロードです。

Grav は、vendor ディレクトリに大量のファイルを抱え込んでいるため、おそらく、いつまで待ってもアップロードが完了しません。  
これを回避するため、 zip のままアップロードすれば、1ファイルなのですぐにアップロードが完了しますが、上記の通り zip ファイルの展開で詰まってしまいます。

ネットで検索すると、裏技として、 php の ZipArchive を使う方法が見つかります。  
しかし、ネット上のプログラムを鵜呑みにはしないでください。  
プログラムの中身や使用方法を十分に確認し、もし安全性の判断が難しいなら、別のレンタルサーバーを利用したり、 Grav 自体を諦める判断も大事です。

あらかじめ、レンタルサーバーの無料期間の間に、 Grav が使えるか、セットアップできるかを試してみることをおすすめします。  
アップロード後は、上記の公式ドキュメントの通り、アップデートやログ確認などを管理パネルから行えます。

## 初期設定の注意点2

上記の通り、 Admin2 付きの zip ファイルをアップロードして、展開した場合、サイトは「管理者の登録画面」になります。

この管理者登録は、セットアップ後すみやかに完了させてください。

WordPress などの場合は、データベース設定（パスワードなど）を知らなければ、管理者は作れない仕組みになっています。  
一方、 Grav の場合は、データベースを使いませんから、誰でも早いもの勝ちで管理者になれてしまう仕様です。

そのため、管理者を登録しないまま放置すると、誰かにサイトを乗っ取られるリスクがあります。 

この状況を回避することは可能です。たとえば：

- ローカル環境でアカウントを作ってからアップロードする
- SSH でアカウントを作ってから Admin2 を有効化する

通常の作業フローで、すぐに自分でアクセスして登録すれば過剰に恐れる必要はありませんが、「放置はNG」「仕様上のリスクがある」ということは覚えておいてください。
