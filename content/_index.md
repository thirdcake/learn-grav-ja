## このサイトについて

このサイトは、日本語ユーザーが [Grav 公式ドキュメント](https://learn.getgrav.org/) を読みやすくするためのサイトです。  
ざっくりと、どこに何が書いてあるのかを解説しています。

以前は、日本語訳の全文を掲載していましたが、 AI 翻訳が十分に発達しましたので、少し内容を変えつつあります。  
公式ドキュメントを日本語にして、それを人間が日本語で読むよりも、 AI に英語で読ませ、その AI と対話したり設定を書いてもらう方が、圧倒的に効率が良くなりました。

Grav には、基本機能でマークダウン出力があるため、 AI との親和性も抜群です。  
ぜひ、このサイトから公式ドキュメントの該当ページを探し、 AI と対話しながらサイト制作や管理にお役立てください。

## Grav CMS について

Grav は、データベースを必要としない、ファイルベースの CMS です。  
以下のような特徴があります：

1. フラットファイル CMS
    - データベース（RDB）を使いません
    - zip ファイルを展開するだけで公開できます
    - マークダウンファイルを書くだけで、記事や一覧画面ができます
    - 全データを自分のディレクトリで管理でき、ベンダーロックインの心配がありません
    - データベース問い合わせが無いので、一般的に高速です
    - SQL インジェクションの心配がありません
1. モダンな構成（Grav 2.0 以降）
    - ファーストクラスの REST API があります
    - ヘッドレス、デカップルド CMS として運用可能です
    - 管理パネルは SvelteKit アプリです
    - AI 向けの MCP サーバーが利用可能です
1. モダンな環境
    - PHP で作られていますが、比較的モダンなフレームワーク（ライブラリ集）の Symfony をベースに作られています
    - 記事がすべてマークダウンであり、設定がすべて YAML ファイルなので、Git 管理との相性が抜群です
1. オープンソース
    - コアや多くのプラグインが MIT ライセンスで、無料で利用できます
    - とはいえ、メンテナーは結構大変なようなので、もし Grav を便利だと感じた方は、プレミアム（有料）プラグインなどを買ってあげてください


## 公式ドキュメントを読み込ませる便利な方法

Grav のデフォルト機能には、サイト URL の末尾に `.md` をつけることで、マークダウン形式（AI が読みやすいフォーマット）のページを表示する仕組みがあります。

**具体例：**

以下の What is Grav?（Grav とは何か？）のページで見比べてください。

- [/what-is-grav](https://learn.getgrav.org/basics/what-is-grav)
- [/what-is-grav.md](https://learn.getgrav.org/basics/what-is-grav.md)

内容は同じですが、人間に読みやすいフォーマットと、 AI に渡しやすいプレーンなテキストがそれぞれ表示されるはずです。

この機能を使って、 AI にマークダウンを読み込ませれば、指示がしやすくなります。  
たとえば、以下のような指示です：

1. 初めて日本語でサイトを作る：
    ```txt
    https://learn.getgrav.org/basics/grav-configuration.md
    上記を参考に教えてください。
    はじめて Grav を設定します。
    system.yaml で日本語を設定する方法を教えてください。
    ```
1. ブログの構築（ページ・コレクション）：
    ```txt
    https://learn.getgrav.org/content/collections.md
    上記を参考に教えてください。
    ブログを作りたいです。
    ブログ一覧ページの設定方法（フロントマターに何を書けばよいか）を教えてください。
    ```
1. テーマのカスタマイズ（子テーマ）：
    ```txt
    https://learn.getgrav.org/themes/customization.md
    上記を参考に教えてください。
    デフォルトテーマ（Quark2）をカスタマイズしたいです。
    ページテンプレートを追加したり、 CSS を上書きしたいのですが、テーマがアップデートされても消えないようにしたいです。
    手順を教えてください。
    ```
1. プラグインの設定（安全なオーバーライド）:
    ```txt
    https://learn.getgrav.org/basics/grav-configuration.md
    上記を参考に教えてください。
    公式の error プラグインの設定をカスタマイズです。
    プラグイン本体をアップデートしても設定が消えないように、設定の上書き（オーバーライド）方法を教えてください。
    ```
1. お問い合わせフォームの設定：
    ```txt
    https://learn.getgrav.org/forms/forms/example-form.md
    上記を参考に教えてください。
    Email, Form プラグインでお問い合わせフォームの内容を自分のメールアドレスに送りたいです。
    設定方法を教えてください。
    ```

さっそく、 [ベーシック](/learn-grav-ja/basics/) から読んでみてください。
