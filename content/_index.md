## Grav CMS について

Grav は、データベースを必要としない、ファイルベースの CMS です。  
以下のような特徴があります：

1. フラットファイル CMS
    - データベース（RDB）を使いません
    - zip ファイルを展開するだけで公開できます
    - マークダウンファイルを書くだけで、記事や一覧画面ができます
    - 全データを自分のディレクトリで管理でき、ベンダーロックインの心配がありません
    - データベース問い合わせが無いので、一般的に高速です
    - SQL インジェクションの心配がありません
1. モダンな構成（Grav 2.0 以降）
    - ファーストクラスの REST API があります
    - ヘッドレス、デカップルド CMS として運用可能です
    - 管理パネルは SvelteKit アプリです
    - AI 向けの MCP サーバーが利用可能です
1. モダンな環境
    - PHP で作られていますが、比較的モダンなフレームワーク（ライブラリ集）の Symfony をベースに作られています
    - 記事がすべてマークダウンであり、設定がすべて YAML ファイルなので、Git 管理との相性が抜群です
1. オープンソース
    - コアや多くのプラグインが MIT ライセンスで、無料で利用できます
    - とはいえ、メンテナーは結構大変なようなので、もし Grav を便利だと感じた方は、プレミアム（有料）プラグインなどを買ってあげてください


## このサイトについて

このサイトは、日本語ユーザーが [Grav 公式ドキュメント](https://learn.getgrav.org/) を読みやすくするためのサイトです。

以前は、全文の日本語訳を掲載していましたが、 AI 翻訳が十分に発達しましたので、少し内容を変えつつあります。  
公式ドキュメントを日本語にして、それを人間が日本語で読むよりも、 AI に英語で読ませ、その AI と対話したり設定を書いてもらう方が、圧倒的に生産的です。  
これにより、自分の書きたいコンテンツに集中できます。

## 公式ドキュメントを読み込ませる便利な方法

Grav のデフォルト機能には、サイト URL の末尾に `.md` をつけることで、マークダウン形式（AI が読みやすいフォーマット）のページを表示する仕組みがあります。

### 具体例：

以下の What is Grav?（Grav とは何か？）のページで見比べてください。

- [/what-is-grav](https://learn.getgrav.org/basics/what-is-grav)
- [/what-is-grav.md](https://learn.getgrav.org/basics/what-is-grav.md)

この機能を使って、 AI にマークダウンを読み込ませれば、指示がしやすくなります。  
たとえば、以下のような指示です：

1. 初めて日本語でサイトを作る：
    ```txt
    はじめて Grav を利用します。初期設定をどこに書けば良いですか？
    また、日本語でサイト制作するときの設定を教えてください。
    ```
2. プラグインの設定（安全なオーバーライド）:
    ```txt
    「○○」というプラグインを入れたいです。
    プラグイン本体をアップデートしても設定が消えないように、設定の上書き（オーバーライド）する方法を教えてください。
    ```
3. テーマのカスタマイズ（子テーマ）：
    ```txt
    「○○」というテーマをもとに子テーマを作りたいです。
    CSS をカスタマイズする程度なのですが、効率的にメンテナンスするやり方を教えてください。
    ```
4. ブログの構築（ページ・コレクション）：
    ```txt
    ブログを作りたいです。
    ブログ一覧ページの設定方法（フロントマターに何を書けばよいか）を教えてください。
    ```
5. お問い合わせフォームの設定：
    ```txt
    Email, Form プラグインでお問い合わせフォームの内容を自分のメールに送りたいです。
    設定方法を教えてください。
    ```

当サイトの役割は、 Grav 公式ドキュメントに、ざっくりとどんなことが書いてあるのかを示すことです。  
これにより、 AI に何を聞けば良いか、わかりやすくなるのではないかと思います。  
Grav でサイトを作るときの第1歩目になれば幸いです。
