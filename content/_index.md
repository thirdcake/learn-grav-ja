## Grav CMS について

Grav は、データベースを必要としない、ファイルベースの CMS です。  
詳しくは： [Grav とは](./what-is-grav/)

## このサイトについて

このサイトは、日本語ユーザーが [Grav 公式ドキュメント](https://learn.getgrav.org/) を読みやすくするためのサイトです。

> [!訳注]  
> 完全な翻訳ではなく、ページによっては抄訳や注記のみのページもあります。  
> GitHub Pages で公開しているため、動的処理の解説は再現できません。  
> そのようなページには、注記および公式ドキュメントへのリンクを貼っています。

## 公式ドキュメントの便利な使い方

Grav のデフォルト機能には、サイト URL の末尾に `.md` をつけることで、マークダウン形式（AI が読みやすいフォーマット）のページを表示する仕組みがあります。

### 具体例：

以下の What is Grav?（Grav とは何か？）のページで見比べてください。

- [/what-is-grav](https://learn.getgrav.org/basics/what-is-grav)
- [/what-is-grav.md](https://learn.getgrav.org/basics/what-is-grav.md)

この機能を使って、 AI にマークダウンを読み込ませれば、指示がしやすくなります。  
たとえば、以下のような指示です：

```txt
このドキュメントを参考に、 Grav で「○○」 がしたいです。
必要な設定を書き、その設定ファイルを置くディレクトリを示してください。
```

## 更新状況

Grav 2.0 以降、開発スピードがとても早く、当サイトの記述は、公式ドキュメントに追いついていないところがあるので注意してください。

基本的には、公式ドキュメントを参照しつつ、もしうまくいかない場合、 [ヘルプ](https://learn.getgrav.org/basics/getting-help) を利用してください。
